Proyecto creado con el objetivo de programar en C++ y desarrollar un motor de físicas simple, como una forma de familiarizarme y prepararme para una asignatura.

Llegado cierto punto del desarrollo, pasé de realizar todo el trabajo por mi cuenta a apoyarme en herramientas de inteligencia artificial, como Anthropic Claude, para agilizar el proceso. Estas herramientas me permiten verificar que mis deducciones sean correctas antes de implementarlas en C++, comprobar que la sintaxis sea adecuada y asegurar que el desarrollo del proyecto mantenga una dirección coherente.

También utilizo herramientas integradas en Visual Studio Code, como Free-Agent Copilot, para revisar el código, comprobar su correcto funcionamiento y generar pruebas de estrés, junto con sus respectivos resultados.
